SYSTEM DESIGN

Project Architecture

Two separate EC2 servers handle CI and CD activities. Nexus transfers the built artifact between the pipelines.

🌍 Application Deployment

AUTOMATION

CI & CD Pipeline

Automated build and deployment using Jenkins pipelines.

🔵 Continuous Integration

CI Server — Build, Test, Analyze and Publish

  • 01. Checkout source code from GitHub
  • 02. Build the application using Maven
  • 03. Execute JUnit and Mockito tests
  • 04. Generate JaCoCo coverage report
  • 05. Analyze code using SonarQube
  • 06. Upload WAR snapshot to Nexus

💜 Continuous Deployment

CD Server — Download and Deploy

  • 01. Start the CD Jenkins pipeline
  • 02. Connect to Nexus on the CI server
  • 03. Download the WAR snapshot artifact
  • 04. Pull the Tomcat Docker image
  • 05. Create the Tomcat Docker container
  • 06. Copy WAR into Tomcat webapps
  • 07. Start Tomcat and verify deployment
